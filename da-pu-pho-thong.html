Frequently asked questions about PU leather

Which PU leather samples are listed?

The catalogue currently shows codes such as UM-76, Valencia, Vegas, Verona and Vicenza. Use the code below the image to request advice; a range name does not replace code-specific specifications.

Is every PU leather code suitable for sofas or cars?

This cannot be determined from a photo catalogue alone. Provide the intended use and project requirements so that specifications, test documents and physical samples can be checked before selection.

What should I ask about the backing and thickness?

The Polyurethane base and nominal 54-inch roll width apply to the synthetic leather ranges. The specification table lists thickness options from 0.5 to 1.4 mm by EN.Base; confirm the sample code, tolerances and usable width when requesting a quotation.

Will the delivered sample match the colour in the photo?

Displayed colours depend on the screen and photography lighting. Approve a physical sample, confirm the colour code and check the batch before volume production.

How can I get advice and a quotation?

Send the sample code, application, estimated quantity and technical requirements through the contact form or Zalo at 0931 792 811. Pricing, physical samples and availability must be confirmed directly.
