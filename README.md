# Tien Phat Materials Website

Static website for `www.tienphat.org`, prepared for GitHub Pages.

## Manual update workflow

1. Edit `index.html` or files in `assets/`.
2. Upload the changed files to the repository and commit.
3. GitHub Pages publishes the new version automatically.

## GitHub Pages settings

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/(root)**
- Custom domain: **www.tienphat.org**

Do not enable the custom domain until the temporary GitHub Pages URL has been tested.
